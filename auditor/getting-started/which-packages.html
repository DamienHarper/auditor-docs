Which packages do I need?

auditor is a family of three packages: pick the one that matches your application

🧭 Pick a package​

Your applicationInstallYou get
Symfony with Doctrine ORMcomposer require damienharper/auditor-bundleauditor + Doctrine provider + configuration, commands, viewer
Doctrine ORM without Symfonycomposer require damienharper/auditor-doctrine-providerauditor + Doctrine provider, wired by hand
Another persistence layer or a custom storecomposer require damienharper/auditorthe core only: write your own provider

auditor-bundle requires auditor-doctrine-provider, which requires auditor: installing the bundle installs the other two.

PackageRole
damienharper/auditorCore: contracts, audit entry model (Entry), attributes, histories, events
damienharper/auditor-doctrine-providerDoctrine ORM change detection, audit tables, schema tools, reader
damienharper/auditor-bundleSymfony integration: dh_auditor configuration, console commands, audit viewer

⚠️ Where the Doctrine provider lives​

  • auditor 5.x: the Doctrine provider is not part of damienharper/auditor any more. Install damienharper/auditor-doctrine-provider (or auditor-bundle, which requires it). The classes keep the DH\Auditor\Provider\Doctrine namespace.
  • auditor 4.x: a copy of the Doctrine provider is still bundled in damienharper/auditor, deprecated since 4.1. auditor-doctrine-provider 1.x is the drop-in replacement.
  • auditor 3.x and earlier: the Doctrine provider is bundled in damienharper/auditor.

🕰️ Older names​

auditor-bundle was formerly known as DoctrineAuditBundle (damienharper/doctrine-audit-bundle). See Coming from DoctrineAuditBundle.
